# Netlify Configuration

This file is used to configure Netlify deployments. Do not delete.

## Build Settings
- **Build Command**: `npm run build`
- **Publish Directory**: `.next`
- **Node Version**: 20

## Plugin
This site uses `@netlify/plugin-nextjs` for optimized Next.js deployments on Netlify.

## Deployment
1. Connect your repository to Netlify
2. Netlify will automatically detect the configuration from `netlify.toml`
3. Push to your repository to trigger a deployment

For more information, visit: https://docs.netlify.com/integrations/frameworks/next-js/
